# M4 provisional structural diagnostics (Phase 1B)

This is a descriptive assessment, not an estimated model. Labels mean: SUPPORTED by repeated historical patterns; PLAUSIBLE but incomplete; UNDECIDED; NOT SUPPORTED by the current evidence.

| candidate block | assessment | evidence and limitation |
|---|---|---|
| Mining | SUPPORTED | Mining is a large, visibly changing nominal GDP share and the four recorded commodities account for about 71–86% of exports in 2011–2025. Project timing and commodity prices/quantities differ. |
| Agriculture | SUPPORTED | Large real contractions/recoveries and extreme quarterly seasonality justify a separate supply block. No dzud attribution is made here. |
| Construction | PLAUSIBLE | Strong seasonality, distinct real growth episodes, public capex relationship, annual GFCF, and distinct employment series support a separate candidate block; quarterly GFCF remains unavailable. |
| Fiscal | SUPPORTED | Revenue, expenditure, balance, and capex show large cyclical episodes and can be expressed consistently relative to nominal GDP. |
| External/trade | SUPPORTED | Exports, imports, balance, commodity decomposition, and quantity/value separation are directly observed. Exchange rate and BOP data remain missing. |
| Price vs quantity in mining | SUPPORTED | Coal and copper implied unit values move differently from quantities; value-only mining measures would conflate channels. |
| Commodity vs project layers | PLAUSIBLE | Commodity series and OT milestones show distinct information; project production/capex schedules are not yet complete enough for estimation. |

## Treatment recommendations

Keep commodity export values and quantities separate. Treat project events as dated evidence/metadata, not as causal dummy coefficients yet. Use raw quarterly values with explicit seasonal handling for descriptive work; later model blocks may use YoY growth or annual data where seasonal noise dominates. No behavioural equations are proposed in this phase.

Construction-block decision: **SEPARATE BLOCK PLAUSIBLE**. The expanded evidence supports a separate candidate block, but quarterly GFCF and project-capex timing remain limitations.
