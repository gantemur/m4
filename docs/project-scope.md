# M4 project scope (Phase 0)

M4 is intended to be a compact, inspectable macroeconomic model for Mongolia. Its provisional production decomposition is

\[
GDP = Y_M + Y_A + Y_C + Y_O + T,
\]

where `Y_M` is mining GVA, `Y_A` agriculture GVA, `Y_C` construction GVA, `Y_O` other-industry GVA, and `T` taxes less subsidies on products. `Y_O` does not include product taxes.

Phase 0 is limited to reproducible foundations: source rules, preliminary data discovery, a minimal NSO data client, a construction-split reconnaissance, and predecessor-model audit. It does **not** estimate behavioural equations, calibrate parameters, run counterfactuals or claim a final sector split.

The proposed future blocks are mining/mineral exports; fiscal revenue and expenditure; agriculture; construction; core non-mining economy; external balance/imports; exchange rate/reserves; simple inflation/monetary effects; and fiscal/sovereign-wealth rules. Their eventual inclusion must be justified by economics and identifiable data, not in-sample fit.
